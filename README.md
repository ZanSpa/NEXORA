# NEXORA

Plataforma de organización estudiantil | Proyecto de prototipo — CBTIS 230

Descripción

NEXORA es una propuesta de plataforma digital diseñada para ayudar a estudiantes a organizar sus actividades escolares desde un solo lugar. Busca reunir herramientas de planificación que permitan consultar horarios, registrar tareas, visualizar fechas importantes y revisar avisos escolares.

El proyecto comenzará con un prototipo visual para evaluar su utilidad y definir una primera versión viable antes de implementar todas sus funciones.

Problema que busca atender

La información relacionada con las actividades escolares puede estar distribuida entre diferentes medios, lo que podría dificultar su consulta y organización. NEXORA propone explorar una solución centralizada para facilitar el seguimiento de responsabilidades y fechas escolares.

Esta necesidad se validará mediante investigación con estudiantes antes de establecer conclusiones definitivas.

Objetivo general

Diseñar y desarrollar un prototipo de plataforma estudiantil que facilite la organización de horarios, tareas, fechas importantes y avisos escolares mediante una interfaz clara y accesible.

Funciones propuestas

- Panel principal: resumen de las actividades próximas.
- Horario escolar: consulta organizada de clases.
- Tareas: registro y seguimiento de pendientes.
- Calendario: visualización de entregas y fechas importantes.
- Avisos: consulta de información escolar relevante.

Etapas de desarrollo

1. Investigar y delimitar el problema.
2. Definir requisitos y funciones prioritarias.
3. Diseñar el prototipo visual.
4. Evaluar el prototipo y recopilar comentarios.
5. Implementar las funciones prioritarias.
6. Probar, documentar y preparar la presentación.

Estado actual

Fase: planificación inicial.

El repositorio y la documentación se prepararán primero. La implementación y las funciones definitivas dependerán de los requisitos del concurso, la investigación y las pruebas del prototipo.

Tecnologías

Las herramientas y tecnologías se definirán durante la planificación técnica.

Contexto

Proyecto en preparación para el concurso de prototipos del CBTIS 230.
